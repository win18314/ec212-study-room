# EC212 · ห้องทบทวนกลางภาค

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจและไม่ต้องใช้อินเทอร์เน็ต

เว็บประกอบด้วยบทเรียน 1–4 ตัวอย่างคำนวณ กราฟประกอบ สูตรและความหมายตัวแปร ตารางอ่าน 5 วัน และปุ่มเปิดเอกสารต้นฉบับ

## โครงสร้างที่ต้องเก็บไว้

```text
EC212/
├── Summarize/
│   ├── index.html
│   ├── styles.css
│   ├── content.js
│   └── study.js
├── Course_Detail.pdf
├── Source/
├── Lecture_Notes/
└── TextBook/
```

ลิงก์ PDF อ้างถึงโฟลเดอร์ข้างเคียงผ่าน `../` จึงควรเก็บ Summarize ภายใน EC212 และไม่เปลี่ยนชื่อไฟล์ PDF เลขหน้าหลัง `#page=` เป็นเลขหน้า PDF ไม่ใช่เลขหน้าที่พิมพ์ในตำรา หากตัวอ่าน PDF ไม่รองรับการกระโดดหน้า ให้ใส่เลขหน้าที่ปุ่มระบุเอง

ตารางใช้วันเริ่มที่เลือกได้และ 20 กิจกรรม รวมวันละ 4 ชั่วโมง ไม่รวมพัก ความคืบหน้าบันทึกใน localStorage ของเบราว์เซอร์นี้เท่านั้น ไม่ซิงก์กับมือถือหรือเบราว์เซอร์อื่น โหมดส่วนตัวหรือข้อจำกัดของเบราว์เซอร์อาจทำให้บันทึกไม่ได้ และหน้าตารางจะแสดงคำอธิบาย การเปิดผ่าน file และผ่าน localhost เป็นคนละแหล่งข้อมูล จึงมีความคืบหน้าแยกกัน

ถ้าต้องการเปิดผ่านเซิร์ฟเวอร์ในเครื่อง ให้เสิร์ฟโฟลเดอร์ EC212 ทั้งชุด ไม่ใช่เฉพาะ Summarize เช่น:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory /Users/win/Desktop/EC212
```

แล้วเปิด `http://127.0.0.1:8765/Summarize/`

## การเรียบเรียงเนื้อหา

- ใช้บทสนทนาเป็นโครง แล้วตรวจ Source ก่อนใช้บันทึกเรียนและตำราเป็นเอกสารเสริม
- ยึดขอบเขตบท 1–4 จาก Course_Detail หน้า 5 พร้อมระบุข้อความขัดกันในหน้า 6 ให้ตรวจประกาศผู้สอน
- นิยาม T ในเว็บเป็นภาษีรวม และ Tnet = T − R; แสดงวิธีแปลงกรณี Source ใช้ T เป็นภาษีสุทธิ
- แยกภาษีเหมาจ่ายกับอัตราภาษี ตัวคูณค่าอิสระกับการเปลี่ยนความชัน และช่องว่างรายได้กับช่องว่างรายจ่าย
- NI/PI แสดงสูตรแบบย่อของวิชาพร้อมเงื่อนไข ไม่อ้างว่าเป็นบัญชีประชาชาติแบบครบรายการ
- บท 2 แสดงวิธี CVM ตามตัวอย่างหน้า 25–26 โดยระบุว่าไม่ใช่นิยามทั่วไปของทุกวิธี CVM
- ตัวอย่างกราฟเป็นภาพประกอบที่วาดจากสมการและพิกัดในบทเรียน ไม่ใช่ภาพคัดลอกสไลด์
- ไม่มีการเผยแพร่เว็บหรืออัปโหลดเอกสารไปยังบริการภายนอก

สำหรับเบราว์เซอร์ที่รองรับ WebMCP เว็บมีเครื่องมืออ่านความคืบหน้าและกำหนดสถานะกิจกรรม โดยใช้การตรวจข้อมูลและการบันทึกเดียวกับช่องติ๊กบนหน้าเว็บ
